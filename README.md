# Контур закупок — пакет для размещения

## Состав

- `index.html` — автономная статическая страница со встроенными данными из книги мониторинга.

## Как открыть

Откройте `index.html` в современном браузере. Для размещения используйте статический хостинг: загрузите `index.html` в корень сайта. Сборка, серверная часть, база данных, платные API и внешние библиотеки не требуются.

Сайт не отправляет данные на серверы. Новые карточки и изменения сохраняются в хранилище браузера; для переноса между браузерами используйте кнопки импорта и экспорта JSON.

## Важно перед публикацией в интернете

Файл содержит данные из исходного реестра закупок и договоров, включая суммы, статусы, имена и контактные данные ответственных лиц. Любой посетитель страницы сможет просмотреть встроенные данные. Используйте пакет только во внутреннем доступе, пока не проверите право на публичное раскрытие этих сведений и не подготовите отдельную обезличенную версию.

Для публичной версии удалите или обезличьте конфиденциальные поля в карточках и проверьте содержание исходных реестров. В текущем пакете разграничения доступа нет.
